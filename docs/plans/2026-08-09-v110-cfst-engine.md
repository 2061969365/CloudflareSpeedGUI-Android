# v1.1.0 内置 cfst 原生引擎改造计划

> 触发：用户指出 (1) 延迟测量用了 TCP ping 而非 cfst 的 -httping；(2) 默认下载地址 https://cf.xiu2.xyz/url 已失效（403）；(3) 未完全复制桌面版全部功能（此项明确列入 backlog，不在本计划范围内）。用户决策：cfst 为主引擎 + Kotlin 自动回退；CI 编译 .so 入库；只修引擎不补功能；发布 v1.1.0。

**目标：** 把 CloudflareSpeedTest v2.3.5 编译为 Android 原生可执行文件打包进 APK，作为主测速引擎（HTTPing 延迟 + 下载测速），Kotlin OkHttp 引擎作为二进制不可用时的自动回退，并修正默认测速地址。

**架构：** jniLibs 打包 `libcfst.so`（GOOS=android，非 linux/arm64）；`android:extractNativeLibs="true"` + `useLegacyPackaging=true` 强制解压使文件可 exec；运行时从 `applicationInfo.nativeLibraryDir` 取路径，`ProcessBuilder` 执行；启动探针 `libcfst.so -v` 检测可用性，失败回退 Kotlin 引擎。

**技术栈：** Go 1.24 (cross-compile)、AGP 9.0.1、Kotlin 2.2.10、JUnit4。

## 关键约束
- cfst 是**批量程序**（不能逐 IP spawn）：一次 `-f ip.txt` 扫描整批 IP，一次 HTTPing（-httping，延迟=HEAD 往返成功样本均值），一次下载测速（-dt/-dn）。
- 交叉编译必须用 `GOOS=android`（不是 linux/arm64）：android 构建读 /system/etc/security/cacerts 真 TLS 校验；linux 构建读 /etc/ssl/certs 在安卓不存在 → HTTPing 全挂。
- `CGO_ENABLED=0` 静态 PIE ELF，改名 libcfst.so，放 `jniLibs/{arm64-v8a,armeabi-v7a}/`。
- manifest 加 `android:extractNativeLibs="true"`；build.gradle 加 `packaging { jniLibs { useLegacyPackaging = true } }`（须 clean rebuild，否则只 dlopen 不落地）。
- 子进程必须设 `TMPDIR=<cacheDir>`（Go os.TempDir 默认 /tmp 不可写）；`-o <filesDir>/result.csv` 用绝对路径。
- 启动探针 `libcfst.so -v` 短超时；IOException errno13=SELinux 拒、exit159=SIGSYS、Exec format=ABI 错 → 回退 Kotlin 引擎。
- 取消：destroy() 后 destroyForcibly()。
- 默认下载地址三处统一改 `https://speed.hatexianyu.ccwu.cc/?bytes=209715200`（桌面版自建 Worker，实测全端口 200）。
